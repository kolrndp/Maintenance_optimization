# Maintenance_optimization
Имитационная модель технического обслуживания оборудования с двумя типами отказов и двухуровневой профилактикой. Модель используется для численной проверки аналитических результатов и исследования коэффициента готовности и средних удельных затрат. Реализованы экспоненциальное распределение и распределение Вейбулла–Гнеденко.
